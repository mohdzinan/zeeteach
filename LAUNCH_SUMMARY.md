```bash

```

**Option 4: GitHub Pages**
- Push to repository

## 📝 Customization Guide

**To change content:**
- Edit `slides-data.js`
- Update slide titles, content, and images

**To change colors:**
- Edit CSS variables in `styles.css`
- Modify the color values in the :root selector

**To add more slides:**
- Add objects to `slidesData` array in `slides-data.js`
- Follow the existing structure (type, title, content/image)
